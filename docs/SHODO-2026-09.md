## 2. 正式スコア（機械が記録するもののみ）

GoatCounter ダッシュボード `https://<GOATCOUNTER_CODE>.goatcounter.com/` で、期間を「直近 7 日」にして読む。

| スコア | 読む場所 | 何を表すか |
|---|---|---|
| 週間訪問 | Pages → トップページの行（path `/kessho/`）の **visits** | URL に来た人の量 |
| `event/return` 件数／週 | Pages → path `event/return`（イベント行）の **visits** | 通う人（観測記録のある再訪）の量 |
| `t.co` 経由訪問／週 | Refs（参照元）→ `t.co` | X の放送から来た人の量 |

- 3 つとも自動で記録される。人手で数えない。
- 読み方の注意: GoatCounter は行ごとに pageviews と visits を出す。**visits** を使う（同じ人の同日リロードを 1 に丸める。イベントも同じ）。合計欄はイベント行（`event/*`）を含みうるので、週間訪問は合計ではなくトップページの行を読む。
- `event/first` は参考値（初観測の数）。判定には使わない。

## 3. 判定値（仮 → 👤 が着手時に確定し、途中で変えない）

| スコア | 判定値（週あたり） | 状態 |
|---|---|---|
| 週間訪問 | **50** | 確定（2026-09-02・オーナー委任により仮値をそのまま採用） |
| `event/return` 件数／週 | **10** | 確定（同上） |
| `t.co` 経由訪問／週 | **15** | 確定（同上） |

- 2026-09-02 にオーナーが判定値の確定を含めて委任したため、仮値をそのまま確定した。計測開始日までは 👤 が差し替えてよい。計測開始日以降は判定日まで数値を変えない（途中で重大な新情報が出ても、判定日に結果と一緒に評価する）。
- 到達判定は **判定日を含む直近 7 日** の値で行う。

## 4. 判定ルール

- 3 つのうち **2 つ以上到達 → 「機械型は効く」**（放送と計測を続け、次の一手を別途決める）。
- **1 つ以下 → 「機械型単体では届かない」**（機械型の放送だけでは足りない、という事実の記録。撤退ではない）。
- どちらの結果でも、ここでは事業性を判定しない。
