# KESSHO — 要件定義 v1.0

対象: アプリ v1.0（試作第四.五稿からの昇格）。スコープ判断の正本。

## 1. スコープ宣言

- **Must（v1.0 に入れる）**: 下記 §2 の3画面＋オープニング＋観測記録（localStorage）＋既存の観測系操作一式。
- **Won't（v1 ではやらない）**: アカウント・DB・通知・他人の結晶（Layer3）・課金・多言語・ライトテーマ。
- 制約: **静的1ファイルで完結**（ビルドは同梱スクリプトのみ・実行時依存ゼロ）。データはビルド時埋め込み（将来 stream.json fetch に差し替え可能な構造にする）。例外は計測ビーコンのみ（DESIGN §14・描画は外部に依存しない）。

## 2. 画面要件（下部タブ3面＋オーバーレイ2種）

### T1 結晶（メイン・起動時）
- 全画面 canvas。三次元結晶（銀河式自転・霧・遠近・脈動・きらめき・塵）。
- 操作: ドラッグ回転（慣性）／ピンチ・ホイールズーム（ダブルタップ解除）／下端の時間スクラブ（106日往復）／粒タップで素性字幕。
- 演出: 彗星着弾（字幕付き）・衝撃波・火花・隣接照明・総括カウントアップ・創世リプレイ（カメラワーク）・ブルーム。
- HUD はすべて canvas 内描画（日付・粒数・スクラブ・字幕・総括）。
- 操作ドロワー（右下 ⚙）: 彩色切替（種別/事業ライン）・凡例タップ絞込・着弾再生（昨夜/一週間/創世）・about。

### T2 夜報（夜ごとの記録＝図鑑）
- 稼働夜の降順リスト。各行: 日付・粒数・行数・種別内訳・その夜のかけら（ミニ結晶）。
- 行タップ → T1 に遷移し**その夜だけの着弾を再生**。
- 行の展開でコミット一覧（時刻なし・件名・行数）。

### T3 記録（あなたの観測＝自分ごとの種）
- タイル: 連続観測（streak）／通算観測回数／初観測日／前回からの差分（+n粒 +m行）。
- 「前回からの着弾を再生」ボタン（差分がある時のみ）。
- データは localStorage のみ（キー `kessho:v1`）。消えても結晶は無傷であることを明記。

### O1 オープニング（毎回・スキップ可）
- 3行の打刻（観測◯日目 → 通算粒/行 → 決め文句）→ フェード → 自動着弾。
- 再訪で差分がある場合は差分文言（「前回から +n粒 / +m行」）＋**差分だけの着弾**を再生。
- タップで即スキップ。reduced-motion では表示のみ・アニメなし。

### O2 about
- 1枚: これは何か／読み方（粒=コミット・半径=log₂行数・熱=鮮度）／データの出所と正直さの規約。

## 3. データ要件

- 入力: `data/stream.json` = 全リポの git 履歴（merge 除外・lockfile 等除外）。1件 = {d,r,l,t,n,s,h}。
- 生成: `scripts/extract-stream.mjs`（ローカル/Actions で実行）。将来は夜間 Actions が毎晩更新（DESIGN.md §5）。
- 決定論: 結晶の形は seed 固定・入力順序のみに依存。同じデータ→同じ形（定点観測の成立条件）。

## 4. 非機能要件

- 60fps 目標（粒270規模）・スプライト事前描画・タブ非表示で描画停止。
- 単一 HTML ≤ 150KB（gz 前）目安。描画の外部リクエストゼロ（CSP 環境でも動作）。例外は計測ビーコン `gc.zgo.at` のみ（DESIGN §14・遮断されても描画は同じ）。
- prefers-reduced-motion で全アニメ静止（静止画＋操作は維持）。
- キーボード: タブ切替ボタンは実 button。canvas 操作の代替として about に説明。
- 端末: iOS Safari / Android Chrome / PC 最新2版。縦画面最適・横も破綻しない。

## 5. 受け入れ基準（テストで担保）

1. 純ロジック（`src/lib.mjs`）の node:test が全緑（PRNG 決定論・DLA 決定論と全粒配置・日次前置換表・訪問状態遷移・投稿文生成 ほか）。
2. ビルド成果物の外部参照は許可リスト（`gc.zgo.at`）のみ。`GOATCOUNTER_CODE` 未設定ビルドでは外部参照ゼロ（DESIGN §14）。
3. 実ブラウザ（headless Chromium）で3画面がスクリーンショット検証済み。
4. 同一データ・同一 seed で結晶座標が再現する（回帰スナップショット）。
