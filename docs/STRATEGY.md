# KESSHO（結晶）— 戦略書 v1.0

作成: 2026-07-30 ／ 位置づけ: 新事業「ダッシュボード先行」路線の小さいサービス第1号。正本はこのファイル（実装との乖離が出たら本書を先に更新）。

## 0. 結論（先出し）

- **製品**: 「結晶 — 夜業の観測所」。AI が毎晩書いたコード差分が、粒子として一つの立体結晶に堆積していく様子を観測する Web アプリ。
- **一言アイデンティティ**: 「AI の夜業を結晶にしている人」。
- **人間性の核**: 蓄積の所有欲 × 毎朝の儀式 × 見逃し回収。ダッシュボード（読む道具）ではなく、**観測所（通う場所）**として設計する。
- **収益の基本形**: 全体（結晶・夜報）は無料。「自分ごと」（自分の観測記録 → 将来は自分の結晶）を有料化する。

## 1. 人間性からの駆動因分析（なぜ人はこれを毎日開くか）

| # | 人間性 | 実装への写像 |
|---|---|---|
| 1 | **蓄積を失いたくない**（保有効果・サンクコストの正の利用） | 結晶は減らない・全歴史が1枚に写る。観測 streak（連続日数）を記録し、切らしたくない気持ちを作る |
| 2 | **儀式が安心を作る**（毎朝同じ動作） | 開くたびに「着弾」が自動再生される数秒のオープニング。毎朝の1タップで完結する |
| 3 | **見逃しを回収したい**（FOMO の健全化） | 「前回の観測から +n粒 / +m行」を検出し、**自分が見ていない間の分だけ**着弾再生する。長く空けるほど豪華になる＝罰ではなく褒美 |
| 4 | **覗き見と本物**（作り物でない証拠を見たい） | 全粒が実コミット。タップで素性（日付・リポ・行数・件名）が出る。誇張なし（半径=log₂行数）を明文化 |
| 5 | **収集と個体愛**（推し・図鑑の心理） | 夜ごとの「かけら」が図鑑になる（夜報）。大きい夜・静かな夜に個体差が出る |
| 6 | **自分の物が欲しい**（所有 → 課金の根） | v1 は「自分の観測記録」（streak・通算・初観測日）。v2 で「自分の GitHub から自分の結晶」＝課金線 |

アンチ要件（人間性に反するのでやらないこと）: 通知でせかさない（v1 は通知なし）／streak が切れても失うのは連続日数だけ（結晶は失われない）／数字の水増し・演出のための架空データ。

## 2. 二層構成の中での位置

- **小さいサービス（本製品）**: 無人運用。毎晩のデータ更新も投稿も機械。オーナーの仕事は「たまに現れて謎に言及する」だけ。
- **大きいサービス（将来・B案）**: 「あなたの結晶」——他人が自分の GitHub を繋いで自分の結晶を育てる。本製品はそのショーケース兼入口。
- 発信との接続: 毎晩のかけら画像＋機械の一文（brypo-landing の publish 経路を再利用）、週次の全景、月次の創世タイムラプス。**X に流れるのは放送、URL に来た人には体験、通う人には記録**の三段。

## 3. 競合と差別化

- GitHub 草・WakaTime 等の活動可視化: 「チャート」であり世界観・物語・儀式がない。
- 生成アート系 (contribution art): 一回性の画像生成であり、**毎晩育つ持続体**ではない。
- 差別化の芯: ①実データの決定論的な蓄積（同じ形が明日も続く）②夜ごとの物語単位（かけら・字幕・総括）③観測という関係性（見る側にも記録が残る）。

## 4. KPI（判断を変える数字だけ）

| 指標 | 見る理由 | 目標（90日） |
|---|---|---|
| 再訪率（7日内） | 儀式が成立しているか | 30% |
| streak 中央値 | 習慣の深さ | 3日 |
| スクショ/共有率（自己申告・リプ観測） | 放送の弾になっているか | 週1バズ（500RT級）×月1 |
| X フォロワー増 | 「◯◯の人」の確立 | +300 |

## 5. リスクと手当て

| リスク | 手当て |
|---|---|
| 初見で「何これ」離脱 | オープニング3行＋about 1枚。説明はデータの字幕に語らせる |
| 夜業が止まる（auto-worker 停止）と枯れる | 静かな夜も細い糸で正直に描く（信用に転化）。7日ゼロなら「冬眠」演出を将来検討 |
| 見た目だけ消費されて再訪しない | 記録（streak・catch-up）が再訪の理由。v1 から入れる |
| Layer3（他人の結晶）に進めない | v1 は静的で完結。v2 要件を DESIGN.md に分離済み |
